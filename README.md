## Tips and Tricks for Best Results

- Use spectrum grab to find harsh resonances, then lower them with narrow Q moves.
- Solo bands while sweeping to hear exactly what each range contributes.
- Apply gentle high-pass filtering to clean low-end rumble on vocals and guitars.
- Use mid-side mode to widen highs on the sides while keeping the center focused.
- Enable dynamic bands for de-harshing vocals without thinning the whole tone.
- Match output level when comparing changes to judge tone rather than loudness.
